Consent Manager Pro

Plugin WordPress gratuit și open-source pentru consimțământul la cookie-uri. Bannerul blochează scripturile și embed-urile până decide vizitatorul. Are Google Consent Mode v2, texte legale și un registru de consimțăminte. Îl face RT. „Pro” înseamnă profesional, nu plătit.
