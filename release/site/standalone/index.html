BiscuitWP fără WordPress

Același banner, pentru un site static sau pe altă platformă, unde poți edita codul paginilor.

De știut înainte: fără WordPress, bannerul blochează doar ce marchezi tu în cod. Dacă nu umbli în codul site-ului, dă pagina asta celui care îl întreține.

Descarcă biscuitwp-standalone.zip

Versiunea 1.2.1, 77 KB, licență GPL. SHA-256: e96c9954678092ca4ac3b5ec2f0e1aea837a9718ecacc12a8eb0e289d62487f5

În arhivă: bannerul (cmp.min.js, cmp.min.css), exemplu.html, pe care îl deschizi cu dublu clic, generator.html și pașii de mai jos în CITESTE.txt.

1. Urcă fișierele

Dezarhivează și urcă folderul biscuitwp în rădăcina site-ului, ca fișierele să se deschidă la site-ul-tau.md/biscuitwp/cmp.min.js.

2. Pune bannerul în pagină

Lipește codul înainte de </head>, pe fiecare pagină (de obicei într-un singur șablon). Schimbă adresa politicii de cookie-uri.

<link rel="stylesheet" href="/biscuitwp/cmp.min.css">
<script>
window.CMP_CONFIG = {
  lang: 'ro', // limba: ro, en, ru
  privacyUrl: '/politica-cookie/', // adresa politicii tale
  categories: ['necessary', 'statistics', 'marketing']
};
</script>
<script src="/biscuitwp/cmp.min.js" defer></script>

3. Marchează scripturile de urmărire

Adaugă type="text/plain" și categoria: statistics pentru statistici, marketing pentru reclame. La scripturile cu adresă, src devine data-cmp-src.

Google Analytics

Înainte

<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

După

<script type="text/plain" data-cmp-block="statistics" data-cmp-src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script type="text/plain" data-cmp-block="statistics">
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

Meta Pixel

Codul din interior rămâne neschimbat; se schimbă doar prima etichetă. Șterge și partea <noscript> a pixelului: ea trimite date fără acord.

<script type="text/plain" data-cmp-block="marketing">

Pentru YouTube, Google Maps și alte conținuturi încorporate, deschide generator.html din arhivă: alegi serviciul și îți dă codul.

4. Pune linkul „Setări cookie” în footer

Vizitatorul trebuie să-și poată schimba alegerea oricând.

<a href="#cmp-settings" data-cmp-settings>Setări cookie</a>

5. Verifică

Deschide site-ul într-o fereastră privată: bannerul apare, iar trackerele nu pornesc înainte de acord. Apoi verifică adresa aici.

Ce nu are față de pluginul WordPress

  • blocare automată și scanarea site-ului;
  • registrul de consimțăminte: nu rămâne o dovadă pe serverul tău;
  • generarea politicilor: textele legale le scrii tu;
  • actualizări automate: descarci din nou arhiva.

Toate opțiunile (aspect, texte, reluarea acordului la servicii noi) sunt în ghidul complet de pe GitHub, în engleză.
