== Description ==

Consent Manager Pro is free and open-source software made by RT (https://rt.md). "Pro" means professional: there is no paid version.

* Consent banner that blocks scripts and embeds until the visitor decides
* Google Consent Mode v2 and Global Privacy Control support
* Configurable categories, cookies and a library of known services
* Legal pages wizard: Privacy Policy, Terms and Conditions, Cookie Policy
* Consent audit log with hashed IPs, retention and CSV/JSON export
* Romanian, Russian and English; works with WPML and Polylang
* No jQuery. The banner itself makes no external requests

Updates are signed (Ed25519) and delivered from https://consent.rt.md/ with no telemetry; the update check sends no site data.

Install from GitHub Releases: https://github.com/rtdesignstudio/consent-manager-pro/releases

Security: https://consent.rt.md/en/security/
Privacy: https://consent.rt.md/en/privacy/

== Installation ==

1. Download the latest zip from GitHub Releases.
2. In WordPress, go to Plugins > Add New > Upload Plugin and upload the zip, or unzip it into `wp-content/plugins/`.
3. Activate the plugin and configure it under Consent Manager.
