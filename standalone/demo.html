Consent Manager Pro — Standalone Demo

Instructions:
  1. Open the browser's Developer Console (F12 → Console tab)
  2. Click "Setări cookie" to open the preferences modal
  3. Toggle "Statistics" and "Marketing" categories on/off
  4. Accept or reject — check the console for tracker script execution logs
  5. The consent is stored in the cmp_consent cookie
Tracker Scripts in This Page:
  • Statistics tracker (external, base64-encoded): blocked until statistics consent is given
  • Marketing tracker (inline): blocked until marketing consent is given
Both will log a message to the console when executed.
