BiscuitWP без WordPress

Тот же баннер для статического сайта или другой платформы, где можно редактировать код страниц.

Важно знать заранее: без WordPress баннер блокирует только то, что вы отметили в коде. Если вы не работаете с кодом сайта, передайте эту страницу тому, кто его обслуживает.

Скачать biscuitwp-standalone.zip

В архиве: баннер (cmp.min.js, cmp.min.css), exemplu.html (пример, открывается двойным щелчком), generator.html (на румынском) и шаги ниже в файле CITESTE.txt.

1. Загрузите файлы

Распакуйте архив и загрузите папку biscuitwp в корень сайта, чтобы файлы открывались по адресу vash-sayt.md/biscuitwp/cmp.min.js.

2. Добавьте баннер на страницу

Вставьте код перед </head> на каждой странице (обычно в одном шаблоне). Измените адрес политики cookie.

<link rel="stylesheet" href="/biscuitwp/cmp.min.css">
<script>
window.CMP_CONFIG = {
  lang: 'ru', // язык: ro, en, ru
  privacyUrl: '/politika-cookie/', // адрес вашей политики
  categories: ['necessary', 'statistics', 'marketing']
};
</script>
<script src="/biscuitwp/cmp.min.js" defer></script>

3. Отметьте скрипты отслеживания

Добавьте type="text/plain" и категорию: statistics для статистики, marketing для рекламы. У скриптов с адресом src заменяется на data-cmp-src.

Google Analytics

До

<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

После

<script type="text/plain" data-cmp-block="statistics" data-cmp-src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script type="text/plain" data-cmp-block="statistics">
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

Meta Pixel

Код внутри не меняется, меняется только первый тег. Удалите и часть <noscript> пикселя: она отправляет данные без согласия.

<script type="text/plain" data-cmp-block="marketing">

Для YouTube, Google Maps и другого встроенного контента откройте generator.html из архива (на румынском): выберите сервис и получите код. Разметка есть и в руководстве на GitHub.

4. Добавьте ссылку «Настройки cookie» в подвал

Посетитель должен иметь возможность изменить свой выбор в любой момент.

<a href="#cmp-settings" data-cmp-settings>Настройки cookie</a>

5. Проверьте

Откройте сайт в приватном окне: баннер появляется, а трекеры не запускаются до согласия. Затем проверьте адрес здесь.

Чего нет по сравнению с плагином WordPress

  • автоматической блокировки и сканирования сайта;
  • журнала согласий: на вашем сервере не остаётся подтверждения;
  • генерации политик: юридические тексты вы пишете сами;
  • автоматических обновлений: архив нужно скачать заново.

Все параметры (внешний вид, тексты, повторный запрос при новых сервисах) описаны в полном руководстве на GitHub (на английском).
