BiscuitWP without WordPress

The same banner, for a static site or another platform where you can edit the page code.

Before you start: without WordPress, the banner blocks only what you mark in the code. If you do not edit your site's code, pass this page to whoever maintains it.

Download biscuitwp-standalone.zip

Version {{VERSION}}, {{STANDALONE_KB}} KB, GPL license. SHA-256: {{STANDALONE_SHA256}}

In the archive: the banner (cmp.min.js, cmp.min.css), exemplu.html, an example you open with a double click, generator.html (in Romanian) and the steps below in CITESTE.txt.

1. Upload the files

Unzip and upload the biscuitwp folder to the root of your site, so the files open at your-site.com/biscuitwp/cmp.min.js.

2. Add the banner to the page

Paste the code before </head>, on every page (usually in one template). Change the address of your cookie policy.

<link rel="stylesheet" href="/biscuitwp/cmp.min.css">
<script>
window.CMP_CONFIG = {
  lang: 'en', // language: ro, en, ru
  privacyUrl: '/cookie-policy/', // the address of your policy
  categories: ['necessary', 'statistics', 'marketing']
};
</script>
<script src="/biscuitwp/cmp.min.js" defer></script>

3. Mark the tracking scripts

Add type="text/plain" and the category: statistics for analytics, marketing for ads. For scripts with an address, src becomes data-cmp-src.

Google Analytics

Before

<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

After

<script type="text/plain" data-cmp-block="statistics" data-cmp-src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script type="text/plain" data-cmp-block="statistics">
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>

Meta Pixel

The code inside stays the same; only the first tag changes. Delete the pixel's <noscript> part too: it sends data without consent.

<script type="text/plain" data-cmp-block="marketing">

For YouTube, Google Maps and other embeds, open generator.html from the archive (in Romanian): choose the service and it gives you the code. The markup is also in the GitHub guide.

4. Put the "Cookie settings" link in the footer

Visitors must be able to change their choice at any time.

<a href="#cmp-settings" data-cmp-settings>Cookie settings</a>

5. Check

Open the site in a private window: the banner shows, and no tracker starts before consent. Then check the address here.

What it lacks compared with the WordPress plugin

  • automatic blocking and the site scan;
  • the consent log: no proof is kept on your server;
  • policy generation: you write the legal texts;
  • automatic updates: you download the archive again.

Every option (appearance, texts, asking again for new services) is in the full guide on GitHub.
